# Francesca’s Cakes

Public mock shop for Francesca Arthur’s bakery in London, Ontario.

- GitHub: https://github.com/primalBeast/francescas-cakes
- Live (GitHub Pages): https://primalbeast.github.io/francescas-cakes/
- Instant public view (until Pages finishes): https://cdn.jsdelivr.net/gh/primalBeast/francescas-cakes@main/index.html

Three cakes (vanilla bean, dark chocolate, lemon with raspberry jam). 6″ $75 / 8″ $115. Finishes: plain, Birthday, Halloween, Pretend Fruit. Checkout is a mock: register and pay feel real, nothing is charged.

Open `index.html` locally, or serve the folder with any static server.
